# Як отримати Windows EXE через GitHub Actions

У цьому середовищі немає Windows, тому створити справжній Windows `.exe` безпосередньо тут неможливо. Додано GitHub Actions workflow, який збирає EXE на Windows-сервері GitHub.

1. Створіть новий репозиторій GitHub або відкрийте свій репозиторій.
2. Завантажте в нього файли цієї папки (включно з прихованою папкою `.github`).
3. Відкрийте вкладку **Actions**.
4. Виберіть workflow **Build Windows EXE**.
5. Натисніть **Run workflow**.
6. Після завершення відкрийте виконаний запуск і завантажте артефакт **Vydacha_Vytyah-Windows**.

Усередині буде `Vydacha_Vytyah.exe`.

Після першого запуску EXE створить папку `data` поруч із файлом. Не видаляйте її — там база даних. Зберігайте папку `data` разом із EXE та робіть резервні копії.
