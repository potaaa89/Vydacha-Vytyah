# Видача витягів — версія 2

## Нові можливості
- захист входу паролем під час першого запуску (від 6 символів);
- зміна пароля з меню програми;
- звіт із підрахунками за роками та місяцями;
- фільтр журналу за роком і місяцем;
- підготовка журналу до друку через браузер;
- експорт поточної вибірки в Excel або CSV;
- резервне копіювання локальної бази даних.

## Запуск
1. Розпакуйте архів у постійну папку на комп'ютері.
2. Встановіть Python 3 з https://www.python.org/downloads/ (позначте Add Python to PATH).
3. Запустіть `Запустити програму.bat`.
4. Під час першого запуску задайте пароль.

## Створення EXE
Запустіть `Створити EXE.bat`. Готовий файл з'явиться в `dist\Vydacha_Vytyah.exe`.
При першому запуске EXE створить папку `data` поруч із собою. Не переміщуйте і не видаляйте її: там зберігається база `vydacha_vytyah.db`.

## Важливо
Це локальний журнал обліку, він не підключається до державного Реєстру та не формує офіційний витяг. Пароль захищає доступ через програму, але не шифрує сам файл бази даних. Для службових персональних даних використовуйте захищений комп'ютер, обмежте доступ до папки програми та регулярно створюйте резервні копії.
